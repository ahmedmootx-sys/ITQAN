# إتقان (ITQAN) — بطاقات تعلّم الإنجليزية بالصوت

تطبيق ويب (PWA) لتعلّم ومذاكرة كلمات الإنجليزية ببطاقات صوتية ونظام تكرار متباعد شبيه بـ Anki، بواجهة عربية كاملة وخطوط مضمّنة، ويعمل بدون إنترنت بعد أول تحميل.

## المزايا

- **603 بطاقة** من كتيّب «أهم 645 كلمة»، كل بطاقة بصوتها من التسجيل الأصلي (نفس الصوت واللهجة).
- **تكرار متباعد** (SM-2 مبسّط): مرة أخرى / صعب / جيد / سهل، مع معاينة الفاصل الزمني لكل اختيار.
- **ثلاثة أنواع تمرين**: قراءة، استماع (تسمع فقط ثم تتذكر)، كتابة (تصحيح تلقائي).
- **مراجعة بالترتيب أو عشوائيًا** — يمكن التبديل من الرئيسية أو الإعدادات.
- **زر تثبيت داخل التطبيق** — يظهر تلقائيًا على أندرويد/كروم، ويعرض خطوات التثبيت على آيفون.
- **استمع وكرّر**: تشغيل تلقائي مع مهلة للتكرار والانتقال بين الكلمات.
- **كلماتي**: إضافة كلمات أو جمل جديدة مع المعنى، ويُولَّد نطقها تلقائيًا (أو اربط تسجيلك/ملفك الصوتي).
- **بحث وتصفية**: جديدة / مستحقة / متقنة / كلماتي.
- **إحصاءات**: تقدمك، سلسلة الأيام، مراجعات اليوم.
- **وضع ليلي** تلقائي/فاتح/داكن.
- **وضع ليلي** (تلقائي/فاتح/داكن).
- **تصدير واستيراد التقدم** (يشمل الكلمات المضافة).
- **تثبيت كتطبيق** على الهاتف بأيقونة الشعار (PWA) وزر تثبيت داخل التطبيق.
- اختصارات لوحة المفاتيح: مسافة (قلب/جيد)، 1-4 (تقييم)، R (استماع)، S (بطيء)، Backspace (تراجع).

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (عام Public).
2. ارفع كل ملفات هذا المجلد إلى الفرع `main` (اسحب الملفات في واجهة GitHub أو استخدم `git`).
3. من المستودع: **Settings → Pages**.
4. تحت **Build and deployment**: اختر **Deploy from a branch**، ثم Branch = `main`، Folder = `/ (root)`، واضغط **Save**.
5. بعد دقيقة سيظهر رابط مثل `https://<username>.github.io/<repo>/` — افتحه من الهاتف.
6. على أندرويد (Chrome): سيظهر زر «تثبيت التطبيق» داخل التطبيق أو من قائمة المتصفح.
   على آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

> ملاحظة: التثبيت يعمل فقط عند فتح الرابط عبر HTTPS (GitHub Pages يوفّره تلقائيًا). لا يعمل من ملف محلي `file://`.

## التشغيل محليًا

- افتح `index.html` مباشرة في المتصفح، أو
- شغّل خادمًا محليًا: `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## بنية المشروع

```
index.html      التطبيق كامل (الواجهة + المنطق + الأصوات مضمّنة)
manifest.json   بيانات تطبيق الويب (الاسم، الأيقونات، الألوان)
sw.js           Service Worker للعمل دون إنترنت
icon-192.png    أيقونة التثبيت
icon-512.png    أيقونة التثبيت (كبيرة)
icon-180.png    أيقونة آيفون
.nojekyll       لمنع معالجة Jekyll على GitHub Pages
```

## ملاحظات

- عدد الكلمات الفريد في الكتيّب 603 (العنوان يقول 645)؛ كل كلمة لها مقطع صوتي مستقل مقصوص من التسجيل.
- التقدم يُحفظ في `localStorage` على الجهاز، ولا يُرسل إلى أي خادم.
- الصوت الأساسي مضمّن داخل `index.html` بصيغة base64، لذلك لا يحتاج التطبيق ملفات صوت خارجية.
